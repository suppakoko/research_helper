**COORDINATOR-LEVEL DECISIONS YOU TOOK**

All are written into `docs/05` §5.5 as "DECIDED 2026-11-02 (coordinator, under `plan/00` §6 item 313)". They still need recording in `plan/00` §6.

1. The inverse document frequency is `ln(1 + (1 + N) / (1 + df))`, which is above 0 for every corpus. A plain `log(N/df)` would zero a word found in every document, so a work in a one-document corpus could not score 1 against itself.
2. Repeats within a field count as `fieldWeight × (1 + ln count)`, and there is no stop-word list. The measurement is below.
3. All fields share one vocabulary, and MeSH descriptors split into words. A descriptor repeated on a merged work counts once.
4. Only `Subject.scheme` `"mesh"` is read. Other schemes, `keywords`, `isMajor` and §7.2's check-tag list are not used.
5. A work with no usable text has an empty vector and scores 0 with everything, including itself. It never produces `NaN`.
6. The score is already in [0, 1], so it must not go through §7.4's `(cosine + 1) / 2`.
7. The label id is `basic-similarity`.

Beyond the card, `LexicalSpace.cosine` throws on a vector from another space, including another corpus, because a different inverse document frequency makes it a different space (`plan/08` §0.2 item 22).

**What it does with Korean and other non-Latin text.** Nothing crashes on any script tested, including mixed text and lone surrogates, and two equal texts always score 1. Overlap is weaker than for English, because words are `normalizeTitle`'s:

- **Korean** splits at spaces only, so `유전자` and `유전자의` are different words and score 0 against each other. A whole space-separated word that recurs does match.
- **Chinese** has no spaces, so a whole run is one word and only an exact repeat matches.
- **Combining marks split words:**
  - Japanese `がん` becomes `か ん`.
  - Thai and Devanagari words break at their vowel signs.
