## Step 1 — can a note parent an attachment? No.

This was read in the installed Zotero 10 client's `omni.ja`. `Zotero.Item.prototype._saveData`, in
`chrome/content/zotero/xpcom/data/item.js`, throws "Parent item … must be a regular item" for any child whose
parent is not a regular item. Its only exceptions are:

- an embedded image, whose parent must be a note;
- an annotation, whose parent must be a file attachment.

So `plan/09` §0.4 line 7's standalone attachment is also the only placement Zotero allows.

**A second rule, from the same source.** A linked file can be in the personal library only. Both `_saveData` and
the `attachmentPath` setter throw "Linked files can only be added to user library". `linkFromFile` in
`xpcom/attachments.js` takes no `libraryID`, and `Zotero.Item.prototype.setCollections` sets an unset library to
the personal one.

Both rules are recorded in `docs/07` §6.5's note of this date and in `src/zotero/attachments.ts`'s header.

## Decisions taken (each DECIDED 2026-11-16, coordinator, under `plan/00` §6 item 313; in `deliver.ts`'s header)

1. **A refusal is returned, not thrown.** The reasons are `read-only`, `no-collection`,
   `linked-needs-personal-library` and `no-folder`, so `P6-T14` can offer "Save as" from one place. A fault while
   writing or attaching still throws.
2. **The mode comes from the assembled size, not from the estimate.** Every chunk check runs before a folder is
   asked for.
3. **A linked file outside the personal library is refused**, pending the owner (item 383, below).
4. **The slug is cut so the whole stem fits the 60-code-point cap.** That cap is `MAX_FILE_STEM_LENGTH`, and the
   slug gets at most 38 code points, so `-trends-<yyyymmdd>-<lang>-NN` is never cut off. `docs/04` §10.3's sketch
   caps the slug alone at 60.
5. **The slug keeps NFC**, not the sketch's NFKD, because NFKD splits Hangul syllables into separate letters.
6. **The date is the local calendar date**, so "the same day" means the user's day.
7. **After a failed import or link, the written file is kept.** It is the only copy of audio that was paid for,
   and `P6-T14`'s "Save as" can use it. After a successful import, the copy is deleted.
8. **The title is in English here** ("Audio report (English), 2026-11-16"), and `P6-T17` passes the localised
   title through `deps.title`.
9. **A same-day re-run gets `-2`, `-3` and so on, up to `-99`.** A name counts as taken if it is in the
   collection's attachment names, or if it exists in the target folder.
10. **A stored or picked folder must exist, be absolute and not be temporary.** A missing stored folder asks again.
    A cancelled or unusable answer is refused as `no-folder`, and nothing is stored.

## Findings

1. **Owner question, `plan/00` §6 item 383: a WAV over 10 MiB cannot be linked in a group library.** This is the
   Zotero rule above. As built, the run is refused before synthesis (option A), which spends nothing. Option B
   would import into the group whatever the size, which uses the group's storage quota. The draft recommends A,
   and it is not adopted. This blocks no `Done when` line. Tag: Phase 6.
