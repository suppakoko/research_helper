## VERDICT
P3-T28 is built except for one step that I stopped on for the owner: **what Generate runs**. The card has no "Open" line, but neither the card nor the documents settle this. docs/08 §3.3 has Generate start the summarize *job* for the one item (`summarizeItems([item.id])`). The P3-T25 note instead names the pane as a direct caller of `summarizeItem`. P3-T29's `SummarizeInput` takes `{libraryID, collectionKey, resummarize, writeNotes}`, so it cannot run a single item.

**Recommendation:** P3-T29's pipeline gains an optional item list, and `publishSummarySection` binds `generate` to a one-item run of it (`regenerate` maps to `resummarize`).

Until that is decided, `generate` is unbound. The section then offers no Generate, Retry or Regenerate button, so no button does nothing. "Save as child note" is also unbound. P3-T29's `writeSummaryNote` exists, but two rules belong to that card: whether the pane skips an item that already has a summary note, and whether it records the note key.

Everything else is built: the factory, the lint entry, the section with all seven states, the escaping of model output, the delete/trash observer, the strings, the unit tests and both integration specs. Card State is still TODO. Nothing was committed. I wrote no `plan/reports/P3-T28.md`, but code comments and the plan note already refer to it, so please save this report there.
