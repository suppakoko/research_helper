   - It also offers Retry from that error: `SOURCE` has no row in `ERROR_ROWS`, so Retry follows the error's own `retryable: true`.
   - The PubMed-only all-failed run has always behaved this way. Open Preferences is unaffected (item 205 stands).

2. **The window's fallback branch is kept but no longer reached by the shipped pipeline.** In `renderSearchOutcome`, the `"partial"` plus `everySearchFailed` branch guards against any other producer of a "partial" output. Its comment now says so. Removing it would break the existing P2-T14 test that feeds a "partial" output.

The doc comment of `src/ui/dialogs/searchDialog.ts` (around line 301) still says "the same with `toIso` moved to today". That file is out of scope and was left alone.
4. **The all-failed `detail` text now lists only the sources that failed.** In the old all-failed case every source had failed, so that text is unchanged.
