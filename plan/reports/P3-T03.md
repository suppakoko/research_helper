How it works:
1. A failed probe still writes `secretBackend = ""`.
2. `installFallbackSecretStore` then sets every `*.keyPresent` flag to false.
3. It awaits the dialog.
4. Only the answer "session" calls `adoptSessionSecretStore`, which writes `secretBackend = "session"` and returns tier 2.
5. `scope.defer` drops the in-memory keys at shutdown.
6. "none", closing the window, a dialog that could not be opened, or no dialog at all (a unit test) all install no store.

The tier-2 store reports `unattended: false`. Its `set` and `clear` keep the flags up to date, and the values live only in the module-level map.
