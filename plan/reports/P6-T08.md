## Decisions taken (each DECIDED 2026-11-17, coordinator, under `plan/00` §6 item 313)

1. **What counts as a numeral.** A numeral is a maximal run of the ASCII digits 0–9. Full-width digits are not
   counted, since the TTS voice reads them as Korean.
2. **How a companion record is recognised.** It is the record `isSameRun` accepts, because the run gives both of
   its records one `generatedAtEpochMs` (`trendReportPipeline.ts`).
3. **The numeral count is logged for every Korean script,** whether it was written from the English report or the
   Korean one.

## Findings

- **No link between a `both` run's two records is stored.** The two records share library, collection and
  instant, but their ids are random and nothing else ties them together. `ReportStore` offers only `put` and
  `get`.
  - This card therefore takes the companion as an optional input, as the card's note allows.
  - The caller (`P6-T16`, which owns `db.ts` and adds a lookup by collection) has to find the companion.
  - This is not a new card: it is in `P6-T16`'s scope.
- **Equivalent mutant (M22).** Removing `companion.language === language` from `chooseScriptSource` changes
  nothing. With two languages, `isSameRun` already requires the companion to be in the other language. The check
  is kept for readability.
