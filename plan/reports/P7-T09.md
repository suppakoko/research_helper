## Decisions (coordinator, under item 313)

1. **The usage total is the sum of the rows shown.** `Cache.stats()` also counts a row whose namespace is not
   one of the seven; such a row has no line, and counting it in the total would break "the rows add up".
2. **Megabytes use the cap's unit**, 1024 × 1024 bytes, as `cacheMaxBytes` in `src/bootstrap/container.ts`
   converts `cache.maxSizeMB`.
3. **The labels say what each number governs**: "Model tasks run in parallel (1–8)" (the `llm` pool,
   `docs/07` §8.5) and "Time limit for one literature database request, in seconds" (LLM attempts have their own
   constant, `docs/07` §7.3's note).
4. **The checkbox writes through the host**, not by `setPref` from the script as `docs/08` §7.3's table says: the
   script writes no preference (its header; `docs/09` §1.9 rule 9).
5. **The data location is the database's file**, as `docs/08` §7.3's wireframe draws it.
6. **`rh-cache-breakdown` is a `div`**, not the `p` the markup draws, because it holds one paragraph per line.
