## What was built

- **`scripts/check-l10n.mjs` (new).** No dependency.
  - `parseFtl(text)` is a line-based reader:
    - an id at column 0 starts an entry, and a comment line ends it;
    - an indented `.attr =` line starts an attribute;
    - any other indented line continues the value or the attribute;
    - a `}` at column 0 continues the entry, because a select expression may close there;
    - any other line is reported as unreadable.
  - `checkLocales({ root, base, target, allow })` compares the two locales, file by file. It reports:
    - files and messages on one side only;
    - attributes on one side only;
    - a value on one side only;
    - empty values and empty attributes;
    - duplicate ids and attributes, and unreadable lines;
    - any `--allow` id that no longer marks a hole.
  - Arguments: `--base`, `--target`, `--root`, and `--allow` (repeatable).
  - Exit codes: 0 when the locales match, 1 on any defect, 2 on a usage error.
  - It never compares the Korean text with the English.
  - **Callers:** the `l10n:check` script in `package.json`, and the lint job's step in `.github/workflows/ci.yml`.
- **`package.json`.** `"l10n:check": "node scripts/check-l10n.mjs --base en-US --target ko-KR"`, the card's text
  exactly.
- **`.github/workflows/ci.yml`.** The placeholder became the step "Verify Korean localization completeness
  (P7-T02)" in the lint job, with a comment on `--allow`.
- **`test/unit/scripts/checkL10n.test.ts` (new, 14 tests).** The script runs as a process on fixture bundles in a
  temporary directory. The fixtures cover:
  - equal locales, a missing id, a missing attribute, an empty value and an extra Korean id;
  - a value on one side only, and a missing file;
  - a duplicate id, an unreadable line and a stale `--allow`;
  - a comment ending an entry, and a select expression closed at column 0.

  Two tests read the CI step itself:
  - one checks that the step is in the lint job, is not `continue-on-error`, and runs `npm run l10n:check`,
    optionally followed by `-- <args>`;
  - the other runs the repository's bundles with that step's own arguments.
