## What was done

1. **The documents (step 1).** Every `addon/content/*.xhtml` file is read. A finding is an element that has visible
   text, a `label`, `placeholder`, `tooltiptext`, `title`, `aria-label` or `alt` holding a letter, or a `value` on a
   button, label or description, and that has no `data-l10n-id`.
2. **The code (step 2).** Every `src/ui/**` TypeScript file and every `addon/content/*.js` file is read. A finding is
   an assignment of a string literal holding a letter to `textContent`, `innerText`, `innerHTML`, `label`, `title`,
   `placeholder` or `tooltipText`, or a `setAttribute` of one of those attributes to such a literal.
3. **The findings (step 3).** The scans found nothing outside an allow-list of 8 entries, each with its reason
   (coordinator, under item 313):
   - four provider names on the preference pane's menu items: OpenRouter, OpenAI, Google Gemini and Anthropic. These
     are product names;
   - four base-URL placeholders. Each is the default address the field falls back to, so it is a URL, not language.

   A test keeps every entry in use, so an entry that stops matching anything fails the test.
4. **`Intl` (step 4).** `src/i18n/format.ts` (new) has seven formatters: `formatUsd`, `formatNumber`, `formatList`,
   `formatMinutes`, `formatBytes`, `formatDate` and `formatDateTime`.
   - Each takes the locale from its caller.
   - The callers are `costConfirmDialog.ts` (whose own formatters moved here), `reportViewModel.ts`,
     `searchImportViewModel.ts` and `summarySection.ts` (the "generated" line).
   - `addon/content/preferences.js` keeps its three helpers, because a chrome script cannot import the bundle
     (coordinator, item 398(f)). The inventory test pins this exception.
5. **Step 5 (item 392(a)): no `detail` on screen.**
   - The item pane's summary section showed `failureText` of a failed run's `detail`. That is free text from outside
     Fluent.
   - The section now holds a `SummaryFailure` built by `summaryFailure(error)`. It has:
     - the error's code, if it is a machine code (`/^[A-Z][A-Z0-9_]*$/`);
     - " · HTTP n", for an integer status from 100 to 599;

   - `textContent` is never set from `detail`.
   - `runItemSummary` (`summarizeDialog.ts`) now throws a `SummaryFailedError`, which carries the code, the message
     key and the status, but not the detail.
   - Tests:
     - `summarySection.test.ts` plants provider text in `detail` and asserts it is not drawn. It also checks that
       every argument-free id exists in both bundles.
     - `summarizePipeline.test.ts` tests the failed outcome.
     - The integration spec `summarySection.spec.ts`, step 6, asserts that the banner holds no planted text, no "from
       provider" and no `[redacted:`, and that the code line is machine-shaped.
