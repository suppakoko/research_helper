## CONTRADICTIONS/FINDINGS
1. **Brief and card disagree on missing fixtures.** The brief says the contract tests skip while fixtures are absent; the card's Done-when says a deleted fixture fails the suite with the record command. I did both, in sequence:
   - Each provider's recorded block skips, with a message, while the provider has no recording at all.
   - From its first recording on, a missing scenario fails with the record command.
   - The synthetic fixtures are always required.
2. **`.github/workflows/ci.yml` is in the card's Files list but needed no change.** Its contract step already runs `npx vitest run --dir test/contract`. Two files outside the Files list were added: `test/contract/llm/_llmContract.ts` (the shared suite) and the `.snap` files.
3. **The request snapshots can differ from what is actually recorded.** The snapshots come from a freshly built adapter; the recorder lists models first, as the product's flow does. For Anthropic, listing can switch structured output from `output_config` to the strict-tool fallback when the catalogue says the model lacks JSON-schema support, and can clamp `max_tokens`. So the recorded `chat-json-ok` request may differ from the Anthropic snapshot. The recorded-response tests list models first to match the recording.
4. **OpenRouter cost may not be reported.** The adapter does not send `usage: {include: true}`. The recorded `chat-nonstream-ok` test asserts `usage.costUsd` is a number, because `docs/07` §5.1 says OpenRouter reports it. If that fails after recording, it is a real finding; the budget guard would then price calls from tokens instead.
5. **The output bound assumes reasoning tokens fall inside `maxOutputTokens`.** `docs/03` §2.6 states this for OpenAI. It is not documented in the corpus for Gemini Interactions or Anthropic thinking. `effort` is left unset (provider default). Either way, the confirmed amount is enforced as a ceiling on reported tokens.
6. **Two scenarios are synthetic rather than recorded:** `error-context-length` and `refusal`. Their contract value is lower, since they only check our error map against our own reading of `docs/03`. The owner may choose to record `error-context-length` later.
7. **Model IDs and prices may be out of date.** They come from the 2026-09-08 table, which the code marks stale. The live run stops before any billed call if the provider does not list the model.
8. **The default spend is cheap only because of one stop.** Without the "Stopped at the spend gate" stop, a mistyped command could spend real money. Test-only keys are built at run time, so the source holds no key-shaped literal that GitHub secret scanning would flag.
9. **The static "no key from any file" test is approximate.** It scans the recorder's source with comments stripped. A behavioural test was added alongside it: a `.env` file in the working directory gives no key.
