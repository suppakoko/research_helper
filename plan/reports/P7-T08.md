## Decisions (coordinator, under item 313)

1. **`sources` stays out of the pane**, against the card's step 1 ("the default sources"). `docs/07` §8.5 places it
   in the search window's checkboxes only, and `docs/08` §7.3 draws no control for it. The card's `Do NOT` forbids
   only adding rows; it does not override §8.5's placement.
2. **No egress-log view**, against step 3. `docs/09` §3.6 item 4 says v1 ships no window for browsing that log; it
   is read from the job records and through the diagnostics bundle (`P7-T13`).
3. **The report language is always shown; only the audio rows hide** while `audio.enabled` is off. Step 2 says "the
   section is hidden"; the report language is not an audio setting.
4. **`tts.linkedFileDir` is shown but not bound.** It is a local path that must be checked before it is written,
   the same reason the base-URL fields are not bound (`docs/08` §7.3, note of 2026-10-23).
5. **The voice list shows names only**, as the report window does. `VoiceInfo.description` is English text, and
   showing it would put untranslated text in the Korean pane.
6. **The privacy line claims no retention.** Strict mode allows providers that keep content for 30 days
   (`docs/09` §3.3, item 270), so the line names only the table's rows.
7. **The full-text labels say "full text", not "PDF full text"**, because Europe PMC full text counts too
   (`docs/06` §5.4's tiers).
