## What was built

- **`src/tts/geminiTts.ts` (new).** `createGeminiTts(deps)` returns a `GeminiTts`, which is a `TTSProvider` with
  `id: "gemini"` plus `listTtsModels`.
  - **`synthesize`** sends one `POST …/models/{model}:generateContent` through the shared HTTP client, with
    `responseModalities: ["AUDIO"]` and the voice in `prebuiltVoiceConfig`. The key goes only in
    `x-goog-api-key` (`geminiHeaders`), and the key is read from `deps.secretId` on every request. The status is
    checked through `mapProviderError` before the body is parsed. `readTtsResponse` returns the decoded PCM, its
    duration, the sample rate from `pcmFormatFromMimeType`, and the usage from `usageMetadata`.
  - **Refusals, each a `TTSError` with its own `context.reason`:** `no-audio`, `unsupported-format` (a mime type
    other than `audio/L16`, or a byte count that is not whole 16-bit frames), `malformed-response`, and
    `model-gone`. `ttsFailureReason(error)` reads the reason back.
  - **`resolveModel`** returns, in order:
    1. `tts.model`, if set;
    2. the recommended model, if the live list holds it;
    3. the first TTS model in the list;
    4. the compiled-in fallback, if the list fetch fails. A cancel or a missing key is not caught, and only the
       error's name is logged.

    An empty list is `model-gone`.
  - **`listVoices`** is `docs/04` §2.7's 30 voices as `VoiceInfo`s, with the default `Charon`.
    **`validateCredentials`** reads the model list and makes no billed call. **`maxInputChars(language)`** is
    `GEMINI_TTS_MAX_CHUNK_CHARS`: 900 for English, 450 for Korean, and 450 for any other language.
- **`src/llm/gemini/mapper.ts`.** `TtsModelEntry` and `readTtsModelList`, beside `readModelList`. They share
  `TTS_MODEL_ID` and keep only the models that support `generateContent`.
- **`src/bootstrap/registerProviders.ts`.** It constructs `createGeminiTts({ secrets, secretId: GEMINI_SECRET_ID,
  baseUrls, http, logger })` beside the Gemini chat provider and returns it as `LLMServices.tts`. Nothing passes it
  to a pipeline yet. The header sentence "TTS providers are Phase 5's" is corrected, with a dated note.
- **`src/model/audio.ts`.** The `rateMeasuredOnModel` comment no longer names a model ID, so the `src` grep finds
  exactly one.
- **`docs/07` §4.4.** An "As built 2026-11-16 (`P6-T05`)" note with the five decisions below.

## Decisions taken (each DECIDED 2026-11-16, coordinator, under `plan/00` §6 item 313)

1. **Every call is `singleAttempt`.** The shared client would otherwise retry at host level, and the card's
   `Do NOT` says that `P6-T11` owns retries.
2. **The four failure reasons live in `TTSError.context.reason`**, and HTTP answers go through the existing
   `mapProviderError`: 400 `API_KEY_INVALID` or 401 is `AuthenticationError`; 403 is `AuthorizationError`; 404 is
   `BadRequestError`; 429 is `RateLimitError` with `retryAfterMs`; 5xx is `UpstreamServerError`; a 200 with
   `finishReason` `SAFETY` is `ContentFilterError`. `P6-T14` turns the reasons into messages.
3. **`resolveModel`'s order and fallback**, as listed above.
4. **`maxInputChars` gives 450 for any language other than English or Korean**, the stricter of the two.
5. **The secret ID is a constructor argument** (`plan/09` §0.4 line 24), and `registerProviders` passes
   `GEMINI_SECRET_ID`.
