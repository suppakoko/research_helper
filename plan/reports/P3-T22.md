## 1. Scoring definition

The scoring rules are recorded in docs/06 §4.3 as "DECIDED 2026-11-10 (coordinator, under plan/00 §6 item 313)", with reasons. The code is `scoreKey`, `truthSpans`, `correctCharacters` and `measureCorpus` in scripts/measure-imrad.ts.

- **Counted characters.** Only body characters count: from the owner's first section start to the end of the text. Text before the first labelled start (title, authors, abstract preamble) is not counted. Character positions are UTF-16 offsets, the same unit the labels use.
- **Truth.** Each owner section runs from its start to the next start. A section's truth is its label set mapped to five scoring classes: introduction, methods, results, discussion, other. Abstract, conclusion and limitations count as "other". Background and related work count as "introduction".
- **Results plus discussion.** A combined results-and-discussion section scores as the set {results, discussion}. A detected span is correct only when its set equals the truth set. Results alone or discussion alone over such text is wrong.
- **"Other".** "Other" is a class like the rest. It is right when both sides say other and wrong when only one side does. "Other" beside a main class is dropped, so {methods, other} scores as {methods}. An empty label set is "other".
- **Detector output.** When the detector declares failure (`sectionAware: false`), every counted character is wrong. That is how the shipped code behaves: the summary gets no sections.
- **Pooling.** The headline is pooled over characters: total correct divided by total counted. The mean of per-paper figures is reported beside it.
- **The bar.** Validated means correct ≥ 0.85 × counted, in whole characters.
- **Papers.** Papers with `hasImradStructure: false` in manifest.json are left out of the pool and reported apart. The five non-heading starts (N1, N2, N3, N6, E5) are scored like everything else.

## 6. Detector defects

Each defect is cited by paper id and 1-based line (counting newline characters) in the fixture text. Per the brief, the detector was not tuned.

- **(a) A heading followed directly by a numbered subheading is missed.** The candidate rule wants the next line to be blank or start with a capital, so a next line starting with a digit fails. Cases: S4 L345 "4 Methods"; E1 L29, L76; W3 L16 "2. Results"; W4 L117, L264; P5 L65, L90; O4 L41; X1 L37, L204; X2 L17, L148, L420; A5 L723. In the excluded paper B2 (L15, L79), the next line starts with a line-number gutter.
- **(b) Roman-numeral numbering is not matched.** The table allows only an Arabic prefix, so no section is recognized. Papers: I1 (for example L12 "I. INTRODUCTION"), I3, I4, I5, A1, A4.
- **(c) Wiley pipe numbering is not matched.** W5 L45 "1 | INTRODUCTION", L121, L190, so W5 declares failure.
- **(d) Decimal subsection numbering is not matched.** A5 L658 "5.1 Methodology", L723 "5.2 Results"; A6 L137, L158.
- **(e) Row order mislabels "Experimental Results" as methods.** The methods row's "experimental" pattern comes first in the table. Cases: X1 L37 "3. Experimental Results"; S1 L135 "Experimental results".
- **(f) Running-text lines that start with a table word are read as headings.** Matching ignores case. Cases: A5 L473 "results in the following update:"; O3 L469 "method".
- **(g) Subsection headings start a new and wrong section.** Cases: O2 L178 "Experimental Computational" (methods inside Results), O2 L224 "Limitations of MD calculations"; E2 L60 "Limitations of the study" inside Discussion.
- **(h) No back-matter row.** Acknowledgements, data availability, funding, author contributions and similar text joins the section before it. This happens across many papers, for example S4 L523–532, W4 L456–479 and B4 L157–173.
- **(i) Section names outside the table.**
  - S1 L19 "Implementation"
  - E2 L62 "STAR+METHODS"
  - E4 L23 "2. Theoretical model"
  - P1 L36 "Literature review" and L61 "Materials & methods" (the ampersand)
  - X2 L84 "3. Data Analysis"
  - XR2 L117, L124, L155, L179
  - the front-matter headings Highlights, Author summary, Significance Statement, Research in context and Nomenclature
- **(j) A run-in heading longer than 90 characters is missed.** N6 L67 "Results Effects of…" is 423 characters.
- **(k) Unheaded introductions, as the owner already knows.** N1 L4, N2 L4, N3 L4, N6 L11, E5 L34. These were not excluded or special-cased.
