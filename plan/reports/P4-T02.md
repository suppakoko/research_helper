**CONTRADICTIONS/FINDINGS**
1. **The schema cannot hold `report.targetWords`'s value set.** §8.5 says "`0`, or ≥ 400". `PrefDef` (§8.5.1, verbatim) has only an inclusive `min`/`max` and a closed `values` list, so a stored 200 is read as 200 instead of falling back to `0`. The schema declares `min: 0`, and a test pins the gap so that closing it later shows up in the tests. Closing it would need a `PrefDef` extension in `src/prefs/index.ts` and in docs/07 §8.5.1, both outside my files. Until then the reader, P4-T08, must handle 1–399. This is not a blocker; it is a candidate for `plan/00` §6.
