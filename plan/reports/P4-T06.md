CONTRADICTIONS/FINDINGS
1. **Owner's call: does a batch answer over its band's maximum stop the run?**
   - Built: yes. Item 292(d) literally covers "a clustering answer", and §20's 4 000-token merge ceiling assumes at most 12 local themes per batch.
   - Problem: the existing message says "more than the { $max } this run's cost was confirmed for", which is inaccurate for a batch (max 7 at 60 papers).
   - Changing it means editing one branch in `runBatch` and the one "[open line]" test.
   - The merge answer's own check against the run's `MAX_THEMES` follows 292(d)'s stated reason directly, so I did not treat it as open.
2. **Latent P4-T05 bug, fixed.** `finalizeClustering` kept a secondary theme id the answer never used when that number happened to be given to `Other`, contrary to docs/12 §8 reading (3). It is fixed, and a new test covers it.
3. **Models with an output limit below 4 000 tokens cannot run two stages.** THEME_MERGE's fixed 4 000-token ceiling would exceed the limit, so the run refuses with `ConfigurationError` before any request. The estimate still prices such a run. P4-T16 or P4-T18 may want to warn earlier.
4. **Only two-stage calls hold a pool permit.** The single-stage THEME_CLUSTER call (P4-T05) still does not take an llm pool permit. P4-T18's call.
5. **Context window still not considered** (P4-T05 finding 8). `ClusterInput.inputBudget` is the hook P4-T22 or P4-T18 can use, but no document says how to derive it from `contextWindowTokens`.
6. **A forced input budget can outrun the estimate.** With a lowered `inputBudget`, partitioning can add batches beyond what the estimate planned. This never happens at the real 60 000.
7. **English reason text may reach a Korean report.** `UNMAPPED_THEME_REASON` is English code-side text, like `SMALL_THEME_REASON`. The report-language label table (P4-T12 / P4-T21) should own it.
8. **No cross-cutting observations after two stages.** Batch observations are dropped because they may name batch-local theme ids, so P4-T08 receives no `crossCuttingObservations` after a two-stage run.
9. **Batch year bounds.** Each batch call is given the run's year bounds, not the batch's own range.
10. **Merge input not measured.** The merge input is not checked against THEME_MERGE's 60 000-token budget. It is bounded in practice by the batch theme limit as built; under the finding-1 alternative it could grow.
