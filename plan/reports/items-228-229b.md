## 6. Contradictions

1. **"After the cap the job fails with a retryable `RateLimitError`" (§7.3).** That holds for a 429. A 5xx that exhausts the cap ends in `UpstreamServerError` instead, which is also retryable. `P1-T05`'s criterion says the same, so the code follows `P1-T05`.
2. **The "4 s worst case" in §7.3 covers only the case where the server sent no `Retry-After`, on the 1000 ms rows.**
   - The longest such wait is 8 s for Semantic Scholar and 12 s for arXiv.
   - A server's `Retry-After` is not limited by the cap, so a host asking for 120 s costs two such waits.
   - A `TimeoutError` is retryable, so a host that never answers costs up to three 60 s timeouts.
   - The dated §7.3 note now states all three.
3. **The arXiv bucket sets the first wait, not the base.** arXiv's first retry reached the wire at 3031 ms instead of its 3000 ms base, because a token at 0.33 per second takes 3030 ms to come back. This is correct: the retry stays under the bucket. But a reader of §7.3 would expect exactly 3000.
4. **"Retry later" and "Retrying in {n}s" now overlap.** `src/ui/viewModels/searchImportViewModel.ts`'s `UNRENDERABLE_ERROR_ROWS` comment says the `RATE_LIMIT` row would be false because "`container.ts` supplies **no `retryFor`**". That reason is now stale: retries do happen, but they finish before the window ever sees the error. Not edited: the file is out of scope.
5. **Two other stale comments.** `src/core/rateLimit/hostLimiter.ts`'s `HOST_POLICIES` header still says "Nothing consumes this field yet … the shipped client still makes exactly one attempt", and §7.3's retry-budget paragraph still says other rows carry `—`. Not edited: the first is out of scope, and §7.3 was limited to dated notes.
6. **An import of supplied records without works is still charged search requests.** That run sends no search either (the records are taken as given), but the owner's decision named only `input.works`, so that case was left alone.
7. **The 0-request estimate assumes Strategy A.** With Strategy B on, a PMCID-only record can cost one NCBI ID Converter request during import. No estimate path counts converter requests.
