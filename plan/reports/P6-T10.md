## Decisions taken (each DECIDED 2026-11-17, coordinator, under `plan/00` §6 item 313)

**In `pricing.ts`:**

1. **Each price row names its TTS model id.** The id sits on a line marked `// PRICE ROW`, and is used only to look
   up a model the run has already chosen. `P6-T05`'s grep criterion now reads "outside the marked price rows", and
   a unit test enforces it: every TTS id in `src/` is either on the fallback line or on a marked row.
2. **The measured rate is a flag on its row** (`audioRateMeasured`), so the model id is not repeated elsewhere.
3. **A user price for a TTS model is looked up under the `gemini` provider.**

**In `estimate.ts`:**

1. **The script step also prices its one conditional retry.**
2. **The 1.15 headroom applies to both the TTS input tokens and the audio tokens.** The script call's output is its
   ceiling, so it gets no headroom.
3. **Speaking time.** Korean is timed by Hangul syllables at 330 a minute, plus any Latin-letter words at 150 a
   minute.
4. **Size and mode.** The bytes and the import-or-link preview come from the unpadded seconds. The file actually
   written decides the mode (`P6-T13`).
5. **Before the script exists**, the TTS figures come from `TARGET_MINUTES` and are marked `provisional`.

## Findings

- **For `P6-T16` (not a new card):** the group-library size check can be fooled near the limit.
  - The import-or-link preview is computed from the unpadded estimate.
  - A group-library report estimated just under 10 MiB can therefore assemble to over 10 MiB and be refused only
    after it was paid for.
  - The refusal before synthesis (item 383, option A) should test the estimate with headroom.
- **The card's grep and its own Files row conflict.** `P6-T05`'s grep criterion forbids model ids in `src/`, but
  this card's table needs them. This was settled by decision 1 above, so it needs no card.
