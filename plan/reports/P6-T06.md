## Decisions taken (each DECIDED 2026-11-16, coordinator, under `plan/00` §6 item 313)

1. **The files are held verbatim and unregistered, not reworded and not registered.** Rewording is forbidden by the
   card, and the Korean wording is the owner's. Registering would make `createPromptRegistry` throw when
   `bundled.ts` is first evaluated, taking every prompt down. This follows the precedent of `THEME_CLUSTER` before
   item 290(b).
2. **They sit in `src/prompts/pending/`, not in `src/prompts/`.** Eight pipeline test files build a registry from
   every `.md` directly in `src/prompts/`: `summarizeItem`, `summarizePipeline`, `recommendPipeline`,
   `recommendProfileCall`, `trendKorean`, `trendReportPipeline`, `trendScale` and `imradAccuracy`. With the files
   there, all eight failed to load. The non-recursive scans skip the subfolder, so no test outside this card's
   `Files` had to change. Once the owner decides, the files move up a level.
3. **`src/prompts/index.ts` and `src/prompts/bundled.ts` are not modified**, although both are in `Files`. Their
   change is step 1's registration, which waits for item 382.
4. **The front matter values.** `outputFormat: text` follows `docs/12` §1.2's "Text". `lastReviewed` is
   2026-11-16, the date of the §14 notes. The variables follow §13's table order, and §14 says "Identical".
5. **The recorder's "ready" means "the file loads", not "the file exists"** (`audioScriptPrompt`). This edits
   `P6-T03`'s file, outside this card's `Files`. Without it, the dry run would call a file that cannot load "ready",
   and the request would then fail.
6. **These files' verbatim test is a block of its own.** The shared `it.each(PROMPT_IDS)` verbatim test cannot
   reach ids that are not registered. Once the files are registered, the shared test covers them, and the block's
   "refused" test becomes a "registered" one.
