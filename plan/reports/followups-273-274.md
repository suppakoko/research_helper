CONTRADICTIONS/FINDINGS
1. Under tier 2, paragraph 4 of docs/09 §1.8 ("It does not protect them … can decrypt them, because your operating system will decrypt them") follows the tier-2 sentence.
   - "It" then has no antecedent, and nothing is encrypted under tier 2.
   - The owner's decision replaces paragraph 1 only, so I left paragraph 4 as it is.
   - The owner may want tier-2 wording for paragraph 4 as well.
2. Tag design. The key uses `cacheEpoch`, but the invalidation tag uses the MAJOR.MINOR line.
   - Why: `cache.lastSeenPromptVersions` stores version strings (the docs/07 §8.5 row was not changed), so an old epoch cannot be recovered at startup.
   - The registry keeps one epoch per line, but it can only check this among the prompt files that are supplied. If a superseded file is dropped and an author breaks the rule, the result is extra invalidation or leftover entries, never a stale summary served.
   - Entries tagged `@1.0.0` under the old format would not be reached. No such entries exist, because nothing calls `createSummaryCache` until P3-T25 is built.
3. `budgetStopOf` with `ceilingStopOf`. If P3-T29 passes `ceilingStopOf`, a `BudgetExceededError` without the context figures is recorded as failed.
   - The runner's default treats every `BudgetExceededError` as a refusal, so it does not have this gap.
   - P3-T29 could pass `ceilingStopOf(e) ?? (e instanceof BudgetExceededError ? e : undefined)`.
4. The pause does not carry the ceiling figures (the `CeilingStop`).
   - P3-T29's surface needs them for `research-helper-cost-ceiling-reached`, and must read them from the guard.
   - A refused call counts twice in `dispatched`: once when refused, once when sent again.
5. `SummaryCacheDeps.promptCacheEpochs` is now required. P3-T25 must pass `PROMPT_CACHE_EPOCHS` next to `PROMPT_VERSIONS`.
6. The tree had changed since wave 6 in files I did not edit. The ko-KR bundle now carries the owner-reviewed Korean for P3-T04 and P3-T16, and `research-helper-prefs-use-translators` exists and is translated. I report this only; I did not touch them.
