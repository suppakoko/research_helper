## Decisions taken (each DECIDED 2026-11-17, coordinator, under `plan/00` §6 item 313; recorded in the `script.ts` header)

1. **"The eleven sections" means §1–§10.** §11's body is the bibliography and the retracted list, which §0.4
   line 15 keeps out. `draftForCritique` (in `critique.ts`) already builds exactly §1–§10, and is reused.
2. **The report's target length is `resolveTargetWords`.** This is the function the report run itself used.
3. **The leak list is the union of `docs/04` §8.5 and `docs/12` §13.** Where one list's test contains the
   other's, the wider test is kept. An empty answer counts as a leak.
4. **The retry appends the correction list to the user message.** The rejected answer is not quoted back.
5. **Cut-off and filtered answers are not retried.** `finishReason` `length` throws `OutputTruncatedError`,
   and `content_filter` throws `ContentFilterError`.
6. **The privacy, tier and egress checks are made in the pipeline.** They belong to `P6-T15` and `P6-T16`,
   which run them before this function is called. `writeScript` takes `beforeSend`.

**The citation format** is decided in `citationMap.ts`:

- The spoken form is "Surname and colleagues, Year", or "Surname, Year" for a single author. With no year, the
  year is left off.
- An item with no surname gets no line and is logged by its key only.
- Surnames are made inert first: control characters become spaces, and the marker characters
  `"`, `→`, `[`, `]`, `|`, `*`, `#` and the backtick are removed.
- Surnames are capped at 80 characters.
