## Decisions taken (each DECIDED 2026-11-17, coordinator, under `plan/00` §6 item 313)

All seven are in the header of `failures.ts`:

1. **401, 403 and a bad key are all `unentitled`.** A 404 is `model-gone` whatever class carries it.
2. **A rate limit is `rate-limited` only once the retries are spent.** The synthesis loop has already retried it.
3. **What keeps its own class:** a quota, a budget pause, a timeout, a network error, a cancellation and anything
   not named above. `unsupported-format` and `malformed-response` read the default variant.
4. **The script is offered whenever one exists and no audio was made**, validated or not, but never after a
   cancellation.
5. **The held audio is the PCM chunks, not a WAV copy.** The WAV is built only when the user saves it.
6. **The script file's first line is built from data only:** the report's title, the language tag and the date.
   So it needs no new string.
7. **The suggested file name** is `<safe collection name> — spoken script <YYYY-MM-DD> (<lang>).txt`.
