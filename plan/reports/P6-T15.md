## Decisions taken (each DECIDED 2026-11-17, coordinator, under `plan/00` §6 item 313)

1. **`gemini.paidTier` is the live declaration.** A `paid` answer sets it. A user who later clears the box in the
   settings gets the free-tier warning back, as `docs/09` §3.6 item 3 says.
2. **The question is offered while the answer is `""` and the key is not already declared paid.**
3. **"Don't know" is pre-selected, and the answer is written only when the dialog is confirmed.** `free` and
   `unknown` leave the paid box as it is.
4. **The refusal is a `PolicyViolationError`** that carries a reason. The audio surface shows its own message,
   `research-helper-audio-tier-refused`, because `rh-error-policy` is still deferred.
5. **The first-use record is a fingerprint kept in the job's egress log:** 16 hexadecimal characters.
   - It is short enough that the redaction gate keeps it, since the gate's hexadecimal pattern starts at 32
     characters.
   - It is far too short to give the key back.
   - Its field name avoids the words that make the gate drop a field. A name containing "secret" would be dropped.
6. **No "don't ask again" for audio.** Every Gemini disclosure already forces the question, so the box could never
   apply.

**Two further readings, in `costConfirmDialog.ts`:**

- Both audio moments are ordinary `preflight` models. So the existing window places every line except the tier
  question.
- Sizes are shown in decimal megabytes, matching `docs/04` §11's "28.8 MB".

## Findings

1. **No card renders the tier question in the dialog's window.** Recorded as `plan/00` §6 item 384, with a draft
   answer that is not adopted.
   - The window script `addon/content/costConfirm.js` has no radio group for the question and sends no
     `tierAnswer`.
   - The window is in no card's Files row.
   - Until it is built, a confirmed audio dialog in Zotero records "don't know", which is the conservative answer.
   - This blocks the question being answerable in `P6-T19`'s acceptance, not this card's criteria.
   - The draft adds the window to `P6-T17`'s Files.
2. **For `P6-T16` and `P6-T17` (not a card).**
   - Show the refusal with `research-helper-audio-tier-refused`, found through `isAudioTierRefusal`, not through
     the error's `messageKey`, which has no message yet.
   - Pass the stored audio jobs to `knownAudioKeyFingerprints`. If old job records are pruned, the first-use
     reason simply comes back, which is the conservative direction.
3. **A defect in `docs/07` that predates this batch (not a card).** A shell expansion replaced several dollar
   amounts in §4.5's note on the report estimate's ceilings. One sentence now reads "5 per million: /usr/bin/bash.51"
   where a price and an amount stood. The correct figures are not recorded anywhere this agent can cite, so they
   were not restored.
