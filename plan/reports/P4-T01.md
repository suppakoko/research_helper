### STAGE-OUTPUT TYPE FIELD LISTS (`?` = optional)

- **`Digest`:** `itemKey`, `lines: DigestLine[]`.
  - `DigestLine`: `kind`, `text`.
  - `kind` is one of `head | question | methods | findings | metrics | theme | keywords | tier`.
- **`ThemeClustering`:** `themes` (at least 1), `assignments`, `unclustered?`, `crossCuttingObservations?`.
  - Each theme: `themeId` (`^T[0-9]+$`), `name` (≤80), `definition` (≤300), `itemKeys`, `rationale?` (≤600).
  - Each assignment: `itemKey`, `primaryThemeId`, `secondaryThemeIds?`, `fit` (strong, moderate or weak).
  - Each unclustered entry: `itemKey`, `reason` (≤300).
- **`ThemeMerge`:** `themes` (at least 1), `mapping` (at least 1).
  - Each theme: `themeId` (`^T[0-9]+$`), `name` (≤80), `definition` (≤300), `rationale?` (≤600).
  - Each mapping entry: `localThemeId` (`^B[0-9]+-T[0-9]+$`), `globalThemeId` (a string or `null`).
- **`ThemeAnalysis`:** `themeId`, `name` (≤80), `narrative`, `representativePapers` (1–6), `methodologicalPatterns?`, `convergentFindings?`, `contradictions?`, `gaps?`, `trajectory` (≤900).
  - Each representative paper: `itemKey`, `why` (≤300).
  - Each methodological pattern: `pattern` (≤300), `itemKeys`.
  - Each convergent finding: `statement` (≤500), `itemKeys` (at least 1), `strength`.
  - Each contradiction: `statement` (≤500), `sideA` and `sideB` (each `claim` ≤400, `itemKeys` at least 1), `possibleExplanation?` (a string or `null`, ≤400).
  - Each gap: `gap` (≤400), `basis` (≤400), `itemKeys?`.
- **`SelfCritique`:** `verdict` (pass, revise or reject), `problems`, `citationCoverage?`.
  - Each problem: `type` (the 8-value enum), `severity` (high, medium or low), `section?` (≤200), `quote` (≤800), `explanation` (≤600), `suggestedFix?` (≤120).
  - `citationCoverage`: `factualSentences?`, `citedSentences?`, `brokenCitations?`.
