## What was built

- **`src/ui/viewModels/relatedViewModel.ts`.** `failedOffline(error, statuses)`: yes for `OFFLINE`, or for `SOURCE`
  when at least one list failed or was rate-limited and every such list's `errorCode` is `OFFLINE`. A list that was
  not asked does not count. `failureView` takes the lists' states as a third parameter. When the run failed offline,
  the headline is `rh-error-offline`, the disclosure keeps the machine code, and Retry is offered. `drawFailure`
  passes the states.
- **`src/ui/viewModels/reportViewModel.ts`.** `stopForFailure(outcome, stop, code)`: the run's own stop if it has one;
  otherwise `rh-error-offline` for a failed run whose code is `OFFLINE`.
- **`src/ui/dialogs/summarizeDialog.ts`.** `SUMMARIZE_OFFLINE_L10N` (`rh-error-offline`, an error id, kept off
  `SUMMARIZE_DIALOG_L10N`); `isOfflineFailure(error)`, which reads `code` only; the model's `offline` line, drawn once.
- **`src/bootstrap/registerUI.ts`.** `createSummarizeSession` sets `offline` on the first paper or run failure that
  `isOfflineFailure` accepts. The report window's `finishRun` and `runJob`'s catch pass the failing code through
  `stopForFailure`.
- **`addon/content/summarize.{xhtml,js}`.** A hidden `rh-summarize-offline` paragraph. The script places the model's
  line there.

Only an error's `code` is read; no message or `detail` reaches a surface (item 389(f)).

## Mutation sweep

Each mutant was planted as a `/* MUTANT` change and the card's tests were run, then the original bytes were restored
and checked byte for byte. **10 of 10 killed:**
- `failedOffline` without its `OFFLINE` short-circuit;
- `failedOffline` with `some` in place of `every`;
- `failedOffline` with a rate-limited list not counted;
- `failedOffline` with an empty list counting as offline;
- `failureView` with the offline headline swapped;
- `failureView` with Retry off;
- `stopForFailure` ignoring the run's own stop;
- `stopForFailure` for any outcome;
- `isOfflineFailure` for any code;
- the summarize model drawing the offline line always.
