## What was done

1. **The search (step 1).** `searchPluginDatabase(needles)` in `test/integration/redactionAudit.spec.ts` works as
   follows:
   - It lists the plugin database's tables from `sqlite_master`, with the `LIKE` pattern bound, and each table's
     columns from `PRAGMA table_info`.
   - It reads every text cell and searches it in the spec.
   - It searches every blob cell in SQL, with `instr` on the cell and the value, both as blobs, so no blob is read
     into the log.
   - The log gets counts only, never a cell, and a hit names only the value's label, the table and the column.
   - The spec's one test calls the search after the existing corpora loop, adds its hits to the test's hits, and
     asserts that at least one table and one text cell were read.
2. **The control (step 2).** The same search, run for a summarized item's key, must find it in at least one cell. A
   search that reads nothing therefore fails.

## Found while building it (fixed; item 398(i), (j))

- **The first run failed with "Please enter a LIKE clause with bindings".** Zotero's connections run on Firefox's
  `Sqlite.sys.mjs`, which refuses `LIKE` followed by a literal. The spec's query wrote `NOT LIKE 'sqlite_%'`. The
  pattern is now bound.
- **The same refusal hit production code.** `pluginDatabaseHasData` in `src/bootstrap/registerUI.ts` had the same
  literal. In Zotero it threw; the pane's catch read that as "no data"; so `docs/09` §1.9 item 8's restore notice
  (`P3-T04`) could not show. Unit tests run on `node:sqlite`, which has no such rule, so none caught it.
  - The pattern is now bound.
  - `test/unit/bootstrap/sqlLikeBindings.test.ts` (new) applies Firefox's expression to `src` and `addon/content`.
  - `preferences.spec.ts`'s `P7-T10` test asserts `pluginDataPresent` in Zotero.
  - Mutation check: putting the literal back is killed by the new test. A lower-case `like` with a literal survives.
    The test matches capitals only, because the plugin's messages use the English word "like"; this limit is stated
    in the test's header.
