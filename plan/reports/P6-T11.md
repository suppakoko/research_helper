## What was built

- **`src/pipeline/audioReport/synthesize.ts` (new).** `synthesizeChunks(input, deps, ctx)` and `STYLE_PREFIX`.
  `STYLE_PREFIX` is `docs/04` §5.3's text, verbatim.
  - **Sending.** Chunks go one at a time, and each attempt goes through:
    - `withRetry`, under `retryPolicyFromBudget(LLM_RETRY_BUDGET)` with `REQUEST_BUDGET_MS`;
    - a per-attempt reservation: `reserveCall` on a run guard, or `reserve`/`settle` on a bare guard, released on
      failure;
    - `ctx.beforeSend`.

    Every attempt sends the same request object.
  - **Fails closed without a budget.** A missing `ctx.budget` is a `ConfigurationError` (item 278(a)).
  - **Resuming.** Finished chunks handed back in `completed` are checked against the plan's requests, and a
    mismatch is a `RangeError`.
  - **Cancel.** It clears the finished chunks and throws `OperationCancelledError`.
  - **Progress.** It goes to `ctx.progress.setProgress(index, total)` and `onChunk`. No user-facing string is set.
  - **The result is a union:**
    - `{ kind: "done", chunks, sampleRateHz, usage }`;
    - `{ kind: "stopped", reason: "budget" | "error", error, completed, pendingIndex }`.
- **`test/unit/pipeline/audioSynthesize.test.ts` (new), 18 tests.**
- **`docs/04` §5.4.** A "Decided 2026-11-16" note:
  - no chunk is written to disk, and finished chunks are held in memory;
  - a retry in the same session reuses them;
  - a timeout is not retried;
  - a change of sample rate stops the run.

**Caller.** `audioReportPipeline.ts` (`P6-T16`), which is not built. It is given a `TTSProvider`, from
`createGeminiTts` in `src/bootstrap/registerProviders.ts`. Nothing constructs the loop itself, because it is a
function.

## Decisions taken (each DECIDED 2026-11-16, coordinator, under `plan/00` §6 item 313)

1. **Prices are injected.** `ttsCostOf` (`P6-T10`) is not built, so pricing comes in through
   `deps.estimateChunk(chunk)`'s `ReservationEstimate.prices`.
2. **The egress log is `P6-T16`'s.** `withEgressLog` decorates a job's input and does not wrap each call. The
   per-call hook here is `ctx.beforeSend`.
3. **A refusal or a provider failure is a returned value, not a throw.** Only a cancel or a broken input throws.
4. **A change of sample rate, or a missing rate, is a `TTSError` with `reason: "sample-rate"`.**
