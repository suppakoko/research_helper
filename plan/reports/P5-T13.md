## Coordinator-level decisions

Each is DECIDED 2026-11-05 (coordinator, under `plan/00` §6 item 313). Recording them in `plan/00` is yours.

1. **`w_dup` and `alreadyOwned` are not applied.** "Exclude outright" contradicts FR-16 and `docs/07` §12.2, and scoring runs before the library is known.
2. **`citeScore` is 1 for any reference or citation edge, and the +0.2 is not built** (finding 1).
3. **Agreement is distinct `RelationEdge.kind` values minus 1.** Two lists of one kind do not agree: they report one fact from two indexes, and which of them ran depends on the budget and the cache. The cap of 3 stays as the doc writes it, though with four kinds it can never apply.
4. **`pmraScore` is `edge.score` as it arrives,** because `rankElinkLinkset` already divided by the list's maximum. Absent or not a number is 0.
5. **`recScore` uses the edge's own `limit` and the work's best edge.** A rank past the limit is 0, never negative.
6. **`SimilarityFn` returns a value already in [0, 1], synchronously.** `P5-T14` rescales SPECTER2 only. What it throws propagates, because mixing two spaces is a defect, not a low score.
7. **`ageYears` is `window.toYear − publishedDate.year`, floored at 0, in calendar years.** `onlineDate` is not a fallback.
8. **`outsideWindow` means older than `window.fromYear`.** A work dated next year is not flagged. A work with no date is not flagged, has `recency` 0 and stays ticked.
9. **Rows come back ranked, highest first; a tie keeps union order.**
10. **Chip ids, in a fixed order whatever the edges' order:** `cites-seed` (`citation`), `cited-by-seed` (`reference`), `recommended`, `similar-pubmed`, `similar`, `citation-context`.
    - `similar` is my reading of the card's list, which names both "similar (PubMed)" and "similar": it is the similarity term, carries the value, and appears when that term is above 0.
    - It has no threshold, because `docs/05` §5.5 says a threshold on one space means nothing on the other.

**Weights.** The six weights, τ = 2.0, the 0.08 and the cap of 3 are unmeasured starting values, shipped as `docs/05` §6.2 suggests them. What would measure them is §8.1–§8.2's held-out precision@k and ablation, which are backlog under item 323(d). **So nothing in Phase 5 measures them.**

## Findings

1. **`docs/05` §6.2's context bonus cannot do anything.** The table says 1.0, plus 0.2 with two or more contexts, capped at 1, which is 1.0 either way. `docs/07` §4.2 repeated it as "reads `contexts.length`". I built no code for it and corrected both documents. Making contexts count would need a base below 1, a number nothing supports. It does not block the phase.

2. **The card's note reads differently from the doc on agreement.** The 2026-11-05 note says "Agreement is the count of distinct `generator` values"; `docs/05` §6.2 subtracts 1. Read without the subtraction, every single-list row would gain 0.08. I followed the doc's subtraction, over kinds rather than generators (decision 3).

3. **Scores are not comparable across a keyed and a keyless run, which matters for `P5-T16`'s dots.** A run without a key has no recommendation term, and the lexical space sits far lower than a rescaled cosine, where a cosine of 0 already reads 0.5. By arithmetic, a citation-only row from this year with no citations and lexical similarity 0.137 (`docs/05` §5.5's same-file average) scores 0.277. On an absolute five-dot scale, keyless rows would therefore sit near the bottom. `P5-T16` should decide the scale. It does not block the phase.

4. **Older rows are flagged, not moved down.** A 2011 reference with 999 citations can rank above a 2026 reference with none, because only the recency and quality terms differ and quality outweighs recency there. A test pins this. I think it is right for FR-18's "discoverable", but the list will not read as newest first.

5. **A row with no date stays ticked.** FR-18's "not silently imported" cannot be applied to a paper with no known age. How many titled candidates arrive undated is unmeasured; `P5-T30`'s run would show it. It does not block the phase.
