CONTRADICTIONS/FINDINGS
1. Gemini in balanced mode. P3-T10 encodes a free or unknown Gemini tier as `trainsOnInputByDefault: "yes"`, and card step 3 refuses "yes" in balanced. So assertModelAllowed refuses every Gemini model in balanced mode for as long as the tier cannot be shown to be paid, which is always today. docs/09 §3.5's table says "Gemini free tier — Balanced: Warned every session". I built the card literally, which is the stricter reading. Owner decision needed.
2. docs/09 §3.5's table says the Gemini free tier is "Warned once" in full mode. §3.6 item 3 and the card say the warning can never be suppressed. I followed §3.6: it is shown on every job.
3. P3-T16 step 2 says "always show the dialog", while docs/09 §3.6 item 2 offers "don't ask again for this collection". mustAskConfirmation only computes whether to ask; P3-T16 has to reconcile the two.
4. rh-error-policy still has no message. assertModelAllowed can now throw PolicyViolationError, but no shipped caller exists, so the key stays deferred and a test asserts that. The card that renders refusals (P3-T16, P3-T29) needs a string.
5. The egress log has no JobRecord member. It rides in `input.egress`, gated by toJobRow. This is my choice, recorded in docs/07 §4.5.
6. Nothing is wired yet:
   - loadPrivacyPolicy, createCollectionSettingsStore (not published by installPluginDatabase), createEgressResumeGuard (not installed as ResumeGuards.egress), and the adapter's global privacyMode getter (registerProviders does not pass it) are all left for P3-T35.
   - The context placeholder is strict.
7. InputScopeKind transcribes docs/07 §5.2's SummaryInputScope["kind"], because SummaryInputScope is not in src yet (P3-T25 adds it). A test pins the four kinds against the document text.
8. Six tests pinned the schema version, not five (the sixth is userPriceStore.test.ts). Five other importers of `privacy: undefined` were outside the Files list (container.ts, three tests, scripts/bench-search.ts) and were edited minimally.
9. The card's Verify filter `"privacyPolicy|provenanceRerun|keys"` matches no test file in Vitest (item 247).
